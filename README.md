# Modular End-to-End-Quantitative-Trading-ML-Predictive-Engine Framework

Automated Data Pipelines & Feature Engineering: 
Diseñé e implementé pipelines de datos en Python para la ingesta, limpieza y normalización de series temporales financieras de alta frecuencia, extrayendo indicadores técnicos y variables predictivas.

Machine Learning Model Iteration: 
Evalué, entrené y optimicé múltiples arquitecturas de Machine Learning (supervisado/no supervisado) aplicadas a la predicción de tendencias de mercado, implementando validación cruzada y Walk-Forward testing para mitigar el sobreajuste (overfitting).

Risk Management & Execution Logic: 
Desarrollé el motor de ejecución automatizada e integración de APIs, programando algoritmos de gestión de riesgo, límites de drawdown y optimización de portafolio.

Full-Stack ML Integration: 
Conecté la arquitectura predictiva con servicios de backend en Python (FastAPI), aplicando patrones de código limpio, pruebas de estrés y monitoreo de rendimiento de métricas clave.


## Key Features

* **Modular Data Pipeline:** Ingests and normalizes multi-source financial market data with automated edge-case handling.
* **Risk & Performance Metrics:** Implemented vectorised calculations for Sharpe Ratio, Sortino Ratio, Maximum Drawdown, and CAGR.
* **Overfitting Prevention:** Built-in Walk-Forward Analysis and out-of-sample testing harnesses to eliminate look-ahead bias.
* **Clean Code Standards:** Fully typed Python 3.10+, PEP8 compliant, modular OOP structure.
> **Note:** This repository serves as a sanitized architectural baseline. Core trading strategies, proprietary feature sets, and trained model weights are excluded for intellectual property protectiion
